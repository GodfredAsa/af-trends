3. Product / domain (README v1)
===============================

[x]  T-shirts with custom designs only
[x]  Public catalog, no login required
[x]  Checkout requires a client account (no guest checkout)
[x]  Staff upload finished designs (customers do not upload artwork)
[x]  Color + size variants with independent stock
[x]  Many images per shirt; optional color tag; one primary
[x]  Cash on delivery only (no card / MoMo / Stripe)
[x]  Order: pending → confirmed → packed → out_for_delivery → delivered
[x]  failed_delivery and cancelled paths
[x]  payment_status unpaid until manager/superadmin marks paid after delivered
[x]  Stock deducted at confirmed, restored if cancelled after confirm
[x]  Roles: guest, client, support, manager, superadmin
[x]  Support cannot confirm, pack, or mark COD collected
[x]  Client can cancel own pending order
[x]  Delivery fee by zone
[x]  Currency GHS (store setting)
[x]  Seeded shirts, palette, zones, four demo users
[x]  JWT auth, bcrypt passwords
[x]  Images stored under api/media, served at /media
[x]  SQLite locally (api/af_trends.db); DATABASE_URL can point at Postgres later

RBAC on the client
[x]  Guest: landing + product + login/register
[x]  Client: cart, checkout, orders, addresses
[x]  Support: dashboard + orders (limited status) + read-only shirts/stock
[x]  Manager: catalog CRUD + full order update/COD/delete (no users/settings)
[x]  Superadmin: users + settings as well
[x]  Privilege matrix in api/app/privileges.py and client/src/privileges.js

7. How to smoke-test
====================

1. Open http://127.0.0.1:5174 — landing loads published tees with photos.
2. Open a shirt, pick color + size, add to cart → redirected to login if guest.
3. Register or sign in as client@aftrends.com → cart → checkout → COD order pending/unpaid.
4. Sign in as manager@aftrends.com → /staff/orders/:id → confirmed (stock drops) → packed → out_for_delivery → delivered → mark paid.
5. Sign in as support@aftrends.com — no Shirts / Users / Settings; cannot confirm or collect cash.
6. Sign in as superadmin@aftrends.com → /staff/users and /staff/settings.
7. Swagger at http://127.0.0.1:8000/docs for the full request/response contract.
